How it works

1 · Data source

Match data comes from TheSportsDB, a free, CORS-friendly football API. No backend or secret keys required, so the whole app runs as static files.

2 · Normalize & render

Raw API responses are mapped to a single match shape, then rendered into score cards. The same renderer drives both live data and the bundled mock data.

3 · Polling & fallback

Scores refresh on a timer (free tiers don't offer push). If the API is unreachable or rate-limited, the app falls back to bundled sample matches so the demo never looks broken.

About this project

LiveKick is a portfolio piece demonstrating real-time data fetching, state handling, graceful degradation, and accessible, responsive UI — all without a framework or build step.
